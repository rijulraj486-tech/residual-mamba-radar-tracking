# Research documentation package

This evidence package supports preparation of an IEEE conference manuscript from completed repository experiments. Start with [MASTER_RESEARCH_DOCUMENTATION.md](MASTER_RESEARCH_DOCUMENTATION.md), then consult the integrity hierarchy and stage-specific reports. All existing experiment artifacts were treated as immutable; package tables and figures are derived copies.

The package deliberately marks unavailable information and distinguishes T=100 extrapolation, Stage 5A screening, Stage 5B confirmation, Stage 6 test results, and Stage 8 information-stratified baselines. See [FINAL_COMPLETION_REPORT.md](FINAL_COMPLETION_REPORT.md) at the repository root for scope and remaining artifact gaps.
