# Validation and checkpoint selection

Validation split is the fixed Stage 2 validation set (204 trajectories per T). Metrics are full-horizon grouped position/velocity/acceleration RMSE and six-state MSE; window metrics are also retained. Best checkpoint is minimum validation six-state MSE, with the configured early stopping settings. Stage 5A's screen compares M0/M1 validation outcomes and uses explicit relative degradation guardrails to admit M1 to five-seed confirmation; screening evidence remains single-seed. Stage 5B performs five matched seed runs and reports per-seed validation plus paired differences. Stage 6 test evaluation is isolated and cannot select/reselect checkpoints. Table/CSV copies are in `results/stage5B_per_seed_validation.csv` and `results/stage5B_validation_windows.csv`; original logs and selection manifest remain in the artifact tree.
