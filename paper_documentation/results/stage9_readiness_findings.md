## 1. Metric consistency

All scored estimates are six-state sequences in `[N,6,T]` order `[x,vx,ax,y,vy,ay]`. The shared metric implementation computes joint x/y group RMSE as `sqrt(mean_t,N(error_x² + error_y²))*1000`; equivalent channel pairs are used for velocity and acceleration. Six-state MSE is the unscaled mean squared error over batch, all six channels, and time. Stage 4/6 and Stage 8 use the same definitions. M0/M1 are evaluated against the Stage 2 state tensor at the same returned index `t`; the filter loops consume observation `t` and store the resulting estimate at `t`. All rows use the full horizon (200 or 400 steps), with no burn-in exclusion.

The Stage 2 stored state coordinates and range are physical values divided by 1,000; bearing remains radians. Mamba outputs and filter states remain in this stored scale until the grouped RMSE is converted to meters, meters/second, or meters/second². Six-state MSE remains in stored-state units. EKF/UKF physical Q is converted by `/1000²`; range variance is scaled by `/1000²`, bearing variance is unchanged, and estimated Q/R are estimated directly in stored coordinates. No position/velocity/acceleration metric or conversion mismatch was found.

| Method | State order | RMSE/MSE | Index/window | First measurement |
|---|---|---|---|---|
| M0/M1 | Confirmed `[x,vx,ax,y,vy,ay]` | Same Stage 4/6 grouped joint RMSE and six-state MSE | `t=0..T-1`, complete horizon | Supplied measurement-derived initializer; each token aligned with returned truth index |
| EKF | Same six-state dynamics | Stage 8 shared metric function | `t=0..T-1`; update result stored at each t | Calibrated prior is `F @ initial_state`; correlated first update accounts for reused initializer observation |
| UKF | Explicitly documented same order | Stage 8 shared metric function | Same full window | Same calibrated prior and a correlated-noise UKF update |
| KalmanNet | Six-state simulator `f` and output | Stage 8 shared metric function | One recurrent update per observation, all T samples | Starts at supplied initializer then predicts once before first observation, matching returned state alignment |

### M1 versus calibrated EKF/UKF acceleration gap

The approximately 5 m/s² calibrated-filter acceleration RMSE versus M1’s 153.4 m/s² at T=200 and 5.8 versus 733.5 m/s² at T=400 is not explained by a metric/index/scaling difference in the reviewed code. The filters use the exact constant-acceleration `F` and nonlinear radar `h`; their calibrated prior is at the right first returned state and both consume the same range-bearing observations. The evaluation applies identical stored-state scoring. The calibrated filters therefore constitute model-informed filters with strong transition structure. The simulator itself follows the same constant-acceleration transition with comparatively small jerk process noise, making acceleration directly constrained by the assumed dynamics. M1 is a learned mapping trained with a six-state objective and lacks that exact recursive filter constraint at inference. This is a legitimate difference in information and inductive bias, not an apples-to-apples learned-model comparison. State explicitly that EKF/UKF know exact `F/h`; the oracle-Q/R variants additionally know manifest noise covariances. Even train-estimated Q/R variants retain exact `F/h`.

## 2. Classical-filter calibration audit

- **Q:** pooled adjacent training-state residuals `x[t] - F x[t-1]`; centered sample covariance with `n-1` denominator. Training split only (819 trajectories at each length), in stored state units. For this simulator this is a direct empirical process-noise estimate, subject to finite sample dependence/finite precision.
- **R:** residuals `z[t] - h(x[t])` conditioned on training ground truth, all training observation times, with bearing residual wrapped to `[-pi,pi)`. Centered sample covariance in scaled-range/radian units. This is ground-truth-conditioned calibration, unavailable to a deployed estimator unless supervised calibration data are available; no test labels used. Treat estimated R as a train-label calibration procedure.
- **P0 and initialization:** generated sequences use two measurements for the MEAS initializer; the second is also returned as observation index 0. The filter prior is initialized at `F @ initial_state`, corresponding to the state paired with returned index 0. P0 is centered sample covariance of `state[:,:,0] - F @ initial_state`; empirical bias is recorded but not applied. Thus prior mean bias is not corrected.
- **First-measurement cross covariance:** centered sample covariance between that prior-state error and the wrapped measurement-noise residual at the first returned observation, conditioned on truth. The formulas in both filters add `C=Cov(e,v)` to state/innovation cross covariance and add `H C + Cᵀ Hᵀ` (or its UKF statistical-linearization analogue) to innovation covariance.
- **EKF approximation:** first-update cross-covariance is propagated with the local Jacobian `H(x_prior)`; update uses a covariance expression equivalent to `P-KSKᵀ`, symmetrizes posterior P. Later standard EKF updates use an explicit innovation inverse and Joseph covariance form. EKF checks finite states/covariances each step and records selected covariance summaries, but does not enforce eigenvalue PSD checks or symmetrize every ordinary update. This is a numerical limitation; Stage 8 recorded all steps finite, not a proof of PSD at every time.
- **UKF approximation/stability:** the nonlinear first-measurement cross covariance is mapped through a statistical regression `H_effᵀ=P⁻¹P_xz`; this is an approximation for nonlinear range-bearing measurement. UKF covariance arithmetic is float64; matrices are symmetrized, materially negative eigenvalues rejected, and Cholesky uses bounded diagonal jitter. State/innovation angle residuals are wrapped. Stage 8 checked finite state/covariance at every step and retained selected covariance snapshots.
- **Covariance checks:** P0 is explicitly symmetrized and its minimum eigenvalue checked; Q/R are sample covariance matrices and thus PSD up to numerical precision. No explicit joint block PSD test for `[P0,C; Cᵀ,R]` is recorded. The first update is mathematically consistent under a jointly Gaussian/linearized error-noise model, but finite-sample P0, C, R are independently estimated and the EKF/UKF nonlinear mappings are approximations. These should not be presented as exact Bayesian first updates.

## 3. KalmanNet stability audit

The archived model applies `nan_to_num` and clamps throughout the computation: state and measurement at ±100, gain at ±5, hidden/internal values commonly at ±20 or ±50; normalized features are sanitized and bounded. Bearing residuals are wrapped, optionally converted to capped-range tangential displacement (range factor 1–5), and the actual state-correction innovation is hard-clipped to ±10 before gain multiplication. Hidden-state initialization and recurrent hidden updates are sanitized. These are active inference safeguards and part of the trained implementation.

Stage 8 records output finiteness/max magnitude/state clip-bound hit count, returned gain norm finiteness/max, and log-innovation finiteness/max. All 10 KNet length/seed rows passed; outputs were finite. It explicitly does **not** instrument internal sanitize/clamp invocations. Existing artifacts cannot recover: per-layer hidden clamp counts/fractions, pre/post-clamp extrema, non-finite replacement counts, innovation component saturation counts, gain element clip counts (only batch gain norms are retained), time-resolved saturation frequency, and whether any replacement/clipping changed the values materially. Output state-bound hits are only a proxy and do not establish absence of internal saturation. Do not claim the model was unclipped or free from internal sanitization.

## 5. Paper-readiness assessment

### Verified claims suitable for a paper

- On the fixed Stage 2 synthetic radar profile, matched-length M1 improves velocity, acceleration, and six-state MSE over M0 at both T=200 and T=400 across all five paired seeds; M1 position is not meaningfully better at T=200 (2/5 seeds improve; mean −0.66%, interval crosses zero), while it is lower at T=400 (5/5 seeds, mean −18.8%).
- Seed-level mean improvements in M1 are 40.4% velocity / 55.6% acceleration / 25.0% six-state MSE at T=200, and 74.4% / 63.6% / 62.4% respectively at T=400. Report as descriptive five-seed results. Stage 7 exact two-sided Wilcoxon p-values have minimum 0.0625 at n=5; do not make a definitive significance claim.
- Matched-length T=200/400 M0/M1 models outperform their respective T=100-to-long Stage 4 counterparts on the same trajectories; frame this as descriptive separately trained model comparisons.
- Stage 8 calibrated model-informed EKF/UKF substantially outperform learned models in acceleration under the exact simulator dynamics. This demonstrates strength of model knowledge and identifies the task’s dynamic prior, not an information-matched learned-method win/loss.
- KalmanNet T=100 cross-length transfer degrades severely on these T=200/T=400 tests. State training horizon and stability safeguards; this does not establish that KalmanNet generally fails when trained at matched length.

### Claims requiring qualification / known limits

- One synthetic motion/noise profile, one simulator family, two horizons; no real radar or out-of-distribution robustness claim.
- Five training seeds and fixed test sets. Stage 6 did not retain per-trajectory outputs/sufficient error contributions, so trajectory-population uncertainty or hierarchical seed/trajectory bootstrap cannot be estimated. Stage 7 seed-level inference is exploratory/low-power and conditional on fixed tests.
- Stage 8 classical baselines have one deterministic result per length/policy, not a seed distribution; methods have unequal information. Runtime comparisons across CPU EKF/UKF and CUDA networks are not algorithm throughput comparisons.
- KalmanNet internal clipping/sanitization rates are unavailable; output finiteness is not sufficient to claim no saturation.
- The calibrated first update is approximate; empirical prior bias is not corrected; joint PSD of separately estimated prior/cross/noise covariance is not recorded.
- Stage 8 provenance hash pointer inconsistency above must be fixed or explicitly disclosed in any archive accompanying submission.

### Tables and figures for a six-page IEEE paper

1. **Main results table:** M0/M1 mean ± SD by horizon; include position, velocity, acceleration, six-state MSE, five seeds. Add a compact column or adjacent table for paired relative differences. Qualify the position result at T=200.
2. **Baseline context table:** calibrated EKF/UKF train-estimated Q/R and (if space permits) oracle-Q/R, plus KalmanNet T100 transfer. Mark classical methods as model-informed and oracle covariance as privileged; clearly separate from M0/M1 seed statistics. Exclude legacy-P0 catastrophic variants from the main table or place in appendix.
3. **Primary figure:** full-horizon or temporal-window position/velocity/acceleration curves with mean and seed SD for M0/M1 and matched lengths. Keep one panel per state group or a two-column composite; ensure axes and units legible.
4. **Secondary figure:** compact paired seed differences/effect plot for M0/M1 by horizon, preferably with raw five points. State uncertainty is over training seeds conditional on fixed test set.
5. Omit extensive runtime/memory plots from the main paper; summarize protocol/device in text and table footnote. Supplement should carry exact configs, calibration equations, hashes, complete per-seed values, all baseline policies, and Stage 7 exploratory tests.

### Recommended narrative

Define the fixed synthetic long-horizon problem and six-state target; explain M0 versus M1 feature treatment and matched-length training. Present seed-paired M0/M1 results first, emphasizing the strongest reproducible changes in velocity/acceleration and the T=200 position caveat. Next show that matched-length training improves over T=100 extrapolation as descriptive evidence. Then place exact-model EKF/UKF and T=100 KalmanNet in an explicitly information-stratified baseline section: strong model-based filtering demonstrates the benefit of known dynamics; KalmanNet provides a cross-length transfer reference. Close with limits on single-profile generalization, five-seed uncertainty, and unavailable trajectory-level uncertainty.
